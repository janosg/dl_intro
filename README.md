# Intro to Deep Learning

Materials for the course "Introduction to Deep Learning and NLP for Economists" at the
University of Bonn. The rendered course web page lives at
https://dl-intro.readthedocs.io.

This repository is also the Python environment for the course. With
[uv](https://docs.astral.sh/uv/) installed, run

```bash
uv sync
uv run jupyter lab
```

in this folder to install all packages and start working on the notebooks in
`docs/source/bld/notebooks`. See the
[installation page](https://dl-intro.readthedocs.io/en/latest/installation.html)
for details.
